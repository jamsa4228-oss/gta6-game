SOLMAR BAY is a fully original open-world crime game in the spirit of GTA 6. Rico Vega owes fixer Marisol Kane $5,000 — pay it off across 4 story missions in a sun-soaked coastal city you explore on foot and by car, with traffic, pedestrians, a 0–5 star wanted level, police chases, combat, and a minimap. Built with three.js, playable offline in a browser, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Controls: WASD to move/drive, mouse to look, E to enter/exit cars, Space to jump, Shift to sprint, R to reload, P to pause. Your progress saves locally.
